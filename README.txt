MUSA - como gerar o APK
1) Suba esta pasta em um host HTTPS (ex.: Vercel: arraste a pasta ou use "vercel --prod").
2) Abra https://pwabuilder.com, cole a URL, clique em Package for stores > Android e baixe o pacote (APK para testar, AAB para a Google Play).
3) Instale o APK no celular. O icone sera a foto da Nise (icons/maskable-512.png).
Para testar sem APK: abra a URL no Chrome do Android > menu > Instalar app.
